# Test Automation School — Coursework

Exercises and assignments from a test automation bootcamp, kept as a record of how I built up automation fundamentals in JavaScript, Python, and Selenium. For my current, production-quality automation work, see [saucedemo-playwright-framework](https://github.com/teefahh/saucedemo-playwright-framework).

## What's here

- **`Module_3/`** — JavaScript fundamentals: functions, loops, objects, and a set of coding challenge assignments
- **`Module_4/`** — Python fundamentals: a series of practice tasks, plus an early Selenium script
- **`Selenium With Python/`** — first hands-on Selenium exercise (launching and controlling a browser)

This is early-stage practice material rather than a maintained project — no ongoing changes expected.
